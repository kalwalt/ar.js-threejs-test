# ar.js-threejs-test

This is a testing repository for AR.js-threejs. The project demonstrates the integration of AR.js with Three.js using Vite as the build tool.

## Project Setup

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/kalwalt/ar.js-threejs-test.git
    cd ar.js-threejs-test
    ```

2. Install dependencies:
    ```sh
    npm install
    ```

### Development

To start the development server, run:
```sh
npm run dev
